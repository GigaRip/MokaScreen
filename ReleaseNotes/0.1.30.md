### New
- The two Macs now synchronize their clocks over the cable. Smooth Motion uses this to keep its schedule fixed, where it used to shift by a few milliseconds when a scroll started or ended.
- The statistics show whether the clocks are synchronized.

### Fixed
- Record to a CSV file no longer leaves an empty file behind when the Macs never connect.

### Note
- Update both Macs. The clocks synchronize only when both run this version.
