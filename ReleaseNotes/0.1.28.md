### Improved
- The Mac you work on now tells macOS it is doing time-critical work while connected, so it is not slowed down when the MokaScreen window is closed or covered.
- Record to a CSV file stays on after you quit, and each row now includes how long the slowest frame took to send and how big it was.
- Seconds in which the picture fell far behind are written to the system log, to help find the cause of occasional slowdowns.
