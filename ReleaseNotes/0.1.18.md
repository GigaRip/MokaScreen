### New
- Develop › Record Frame Timing (⌥⌘T) records 10 seconds of how every frame travels from the extended display to the display Mac's screen: when it was captured, whether a newer frame replaced it before sending, when it was sent, received and drawn, and when it reached the screen. The result is one CSV file in the statistics folder, shown in Finder when the recording ends. Use it on the Mac you work on while the picture is showing.

### Note
- Update both Macs. A display Mac on an older version leaves its columns empty.
