### New
- MokaScreen › Settings (⌘,) holds the settings that used to be in the Develop menu: Smooth Motion, its smoothness margin, holding the display at 120 Hz, and showing statistics. They are still kept the same on both Macs.

### Changed
- The Develop menu is hidden unless you turn on Developer mode in Settings. It now holds only measuring tools: Record Frame Timing, Show Latency Clock, Start Loopback Test, and Open Statistics Folder.
- The keyboard shortcuts for Show Statistics, Smooth Motion and Fixed 120 Hz are gone, since those are now settings.

### Note
- If you used the Develop menu, turn on Developer mode in Settings to get it back.
- Update both Macs.
